# コメント明細を表示する検証

前回の集計のみの記録はそのまま残す。本文を削除済みなので、明細の確認には新しい取得が必要。
この更新だけでは有料取得は始まらない。利用者のMacで明示的に実行する。

## 範囲

投稿情報1件、コメント最大20件（無料プランでは15件の場合あり）。返信なし。
課金枠は合計0.10 USD、保守的な円換算30円、検証予算300円内。
プロフィール詳細取得、いいねユーザー取得、OpenAIによる属性・選定理由の判定はまだ行わない。

## 実行（新しい有料検証）

```sh
npm run p0:probe -- --url "https://www.instagram.com/p/対象投稿ID/" --retain-comments
```

上は通信なしの計画表示。範囲と費用を確認してから、末尾に `--execute` を追加する。
記録は `.p0-results/comments-対象投稿ID.json` に保存する。
同名記録が存在すれば実行を止める。失敗時は自動再実行しない。
外部ストレージは従来どおり削除し、本文・ユーザー名はローカルJSONにのみ残す。
本文は最大4000文字、最大20件。画像・メール等の追加フィールドは保存しない。

## UI

「実データの取得記録」で投稿URLと新しいcommentsファイルを選ぶ。
コメント一覧、ユーザー名、Instagramプロフィールリンクを表示する。
属性・選定理由は未判定と表示し、架空の結果を混ぜない。
インポートは課金なし。同一URL・実行日時の再インポートは重複保存しない。

## 保持と共有

Web側の取り込み記録は90日削除対象。ローカルJSONは自動削除されないため、確認後に削除する。
共有PC・GitHub・チャットに実データJSONを載せない。現段階ではローカルでの検証専用。
社外テスターに明細を共有する前に招待認証・アクセス制御・削除運用を完成させる。
