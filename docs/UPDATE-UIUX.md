# UI・UXの更新

## 変更点

- 集計レポートとユーザー一覧を画面内で切り替え。長いレポートの末尾までスクロールせず一覧へ移動できます。
- 集計から「高関心の人を見る」でユーザー一覧を絞り込み表示。
- 一覧は名前・反応・属性・タグ・スケート判定の短い行に整理。詳しい根拠・判定条件・確信度は「詳細」の右側パネルで確認できます。
- タグクリックによる絞り込み、スコア順・タグ数順の並び替え、20人ずつのページ送り、検索クリア。
- スマホではユーザー一覧をカード表示、主なナビゲーションを下部に配置。
- 文字のコントラスト・余白・フォーム・ボタンサイズを全体で統一。
- 登録フォームに手順表示とキーボードのフォーカス制御を追加。
- 詳細パネルはEscapeで閉じられ、一覧の元のボタンにフォーカスが戻ります。
- 反応タブは左右矢印・Home・Endキーで切り替え可能。
- 完了レポートの不要な繰り返し取得を停止。
- 個人情報の保護、10代の非表示、モックProviderの動作は継続。

## Macでの更新方法

1. `reach-insight-uiux-update.zip` をダウンロードフォルダに保存します。
2. 起動中のデモのターミナルで Control+C を押します。
3. 以下を1行ずつ実行します。

```bash
unzip -o ~/Downloads/reach-insight-uiux-update.zip -d ~/Downloads/reach-insight
npm run dev
```

http://localhost:3000 を再読み込みして、既存の分析結果を開いてください。
新しい「ユーザー一覧」ボタンで切り替え、「詳細」から理由を確認できます。
設定ファイルとDBは変更しません。再インストール・再分析は不要です。
