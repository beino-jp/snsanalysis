# 実ユーザーの属性・関心分析（ローカル検証）

コメント一覧の表示から、公開プロフィールを根拠にした属性と関心の分析へ進むための処理。
完成したプロダクトのWeb有料実行導線とは別の、Macでの検証用CLI。

- 入力は取得済みcomments JSON。コメントの再取得はしない。
- 最大20人の公開プロフィールを公式Profile Scraperから取得。
- 自己紹介とレスポンスに含まれる直近投稿テキスト最大20件を使用。各人のAI入力本文は合計1500文字まで。
- 投稿専用Actorでの追加取得はまだ行わない。プロフィールレスポンスに投稿がなければ自己紹介だけで判定する。
- 非公開アカウントは判定しない。画像は使わない。
- 性別・年代は明示的な自己記述のみ。根拠が足りなければ不明。関心には原文引用を要求し、入力にない引用は落とす。
- 健康・宗教・政治等のセンシティブな属性は推定しない。出力は推定であり、引用があることだけで意味の正しさを保証するものではない。
- 今回は属性・関心分析まで。案件適合スコアと目的の聞き返しは未接続。

## 料金と実行

`.env` の `OPENAI_INPUT_USD_PER_MILLION` と `OPENAI_OUTPUT_USD_PER_MILLION` に、gpt-4.1-miniの利用時点の公式料金を設定する。未設定・予算超過は実行停止。
モデルはgpt-4.1-miniに限定。Apify上限$0.10、AI入力は安全側に150,000トークン・出力は人数×1600トークンとして事前計算し、300円枠を超えれば停止。
料金の変更・契約による差は実行前に確認する必要がある。新しい外部通信はMacで明示実行した場合のみ。

```sh
npx tsx scripts/analyze-audience.ts --file .p0-results/comments-対象投稿ID.json
```

上記は通信なし。計画確認後に末尾へ `--execute` を付けて実行する。
同名audienceファイルがあると停止する。タイムアウトや課金の不明時に自動再試行しない。
プロフィールの外部保存先は削除。AIはstore:falseで利用。ローカルJSONに根拠引用と属性が残るため、共有・Gitへの登録は禁止し、確認後に削除する。

## UIへの反映

完了した `.p0-results/audience-対象投稿ID.json` を同じ「実データの取得記録」で読み込む。
性別・年代の分布（不明を含む）、関心、判定理由、引用根拠を先に表示。
10代と判定した対象のプロフィールリンクは表示しない。
DBは90日削除対象。ローカルファイルの自動削除は未実装。

この機能の実API検証は、ユーザーのMacで行う必要がある。クラウド作業環境にはAPIキーを置いていない。
