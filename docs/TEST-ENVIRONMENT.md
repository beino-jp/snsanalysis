# 先方テストまでの実装・公開条件

> 2026-11-27更新：配備方針はCloudflare主体へ訂正。VPS契約は不要。最新の実装順は [CLOUDFLARE-ARCHITECTURE.md](CLOUDFLARE-ARCHITECTURE.md) を参照。以下のVPS/Docker手順は任意の代替案であり、ユーザーへ契約を要求しない。

## 今回の確認

実データの取得記録画面で、Macに残った `.p0-results/probe-投稿ID.json` を読み込む。
投稿URLを入力しJSONを選択すると、表示いいね数、表示コメント数、取得コメント数、ユニーク人数、取得率とAPI返却費用を表示する。
本文・ユーザー名は保存しない。インポートは外部APIを実行しない。
アップロードされた記録を表示する機能であり、Apifyへの再照合や属性判定ではない。

### Macの更新

1. 更新ZIPをDownloadsに保存する。
2. アプリを実行中ならターミナルでControl+Cを押す。
3. 次を順に実行する。

```sh
cd ~/Downloads/reach-insight
unzip -o ~/Downloads/reach-insight-validation-ui-update.zip -d .
npm run db:setup
npm run dev
```

4. `http://localhost:3000` にログインして「実データの取得記録」を開く。
5. 検証した投稿URLを入力する。ファイル選択画面でCommand+Shift+Gを押し、`~/Downloads/reach-insight/.p0-results/` を入力して該当JSONを選ぶ。
6. 「記録をUIに表示」を押す。再取得コマンドは実行しない。

## 次の実装順序

1. 実取得データのUI確認を完了する。
2. コメント取得→必要な公開プロフィール→AI判定→集計→一覧をつなぐ。既に削除した明細は復元できないため、必要なら予算を明示した新しい検証を行う。
3. 目的の入力、不足条件の質問、評価基準の確認、根拠付きスコアを実データで接続する。
4. 候補探索は別の有料処理として接続。最大100候補×20投稿、推薦最大10人、1回3,000円上限と月間予算を予約・精算で制御する。
5. 招待したテスターのみが利用できる共有開発環境へ公開する。

## 共有開発環境の構成

CloudflareでDNSとHTTPS入口、常時動作するサーバーでNext.jsとワーカー、SupabaseでPostgreSQLと認証を利用する案。
Cloudflare DNSだけではアプリやワーカーは実行されない。
開発用DBとAPIキーは本番から分ける。外部公開時にDEMO_AUTHを有効にしない。
現在、サーバー契約・ドメイン・公開設定は未完了であり、この文書だけではデプロイされない。
月額10,000円以内の配分はPRODUCT_PLAN.mdを参照し、契約前に現行料金を確認する。

## 先方へ渡す前の受け入れ条件

- HTTPS URL、招待ログイン、メール許可リスト、無関係なアカウントの拒否。
- 管理者によるユーザー無効化、セッション失効、ログイン試行制限。
- 実データとモックの明確な表示、取得不足や判定不能を隠さない表示。
- 登録→実行→進捗→結果→プロフィール導線までのブラウザ検証。
- 有料実行前の見積もり、上限到達時の停止、重複実行防止。
- DBの権限、秘密のサーバー側保管、バックアップと復旧、90日削除の確認。
- 失敗・再開、外部APIのタイムアウト、削除失敗の運用確認。
- テスト用案件・操作手順・問い合わせ方法を用意する。
