# 分析済みユーザー一覧の更新

分析結果の下部に、公開アカウントの分析済みユーザー一覧を追加しました。
- いいね・コメント・ユニークの各タブと連動
- 名前で検索、該当タグ・スケート判定で絞り込み、10人ずつ表示
- タグごとに判定条件、根拠、確信度を表示
- 性別・年代の推定根拠、スケートの点数と理由を表示
- ユーザー名クリックでプロフィールを別タブ表示
- デモは架空プロフィール画面。実データではInstagramのプロフィールURL
- 10代はAPIの段階で名前・リンク・根拠の文章を非表示

過去の分析結果にも一覧が表示されます。再分析やDB変更は不要です。

## Macで今のデモを更新する

1. 更新ZIPをダウンロードします。ZIPは解凍せずダウンロードフォルダに保存してください。
2. デモを動かしているターミナルで Control+C を押して停止します。
3. 次のコマンドを実行します。

```bash
unzip -o ~/Downloads/reach-insight-user-list-update.zip -d ~/Downloads/reach-insight
npm run dev
```

4. http://localhost:3000 を再読み込みして完了済みの分析結果を開き、下にスクロールします。

このZIPには変更したソースのみが入っています。.env・依存関係・DBは変更しません。
